# Shared tutorial data

`input.txt` is the Tiny Shakespeare corpus used by the first tutorial. It is shared by Python, C, and Java so each implementation reads identical bytes.

The file comes from [Karpathy's char-rnn repository](https://github.com/karpathy/char-rnn/blob/master/data/tinyshakespeare/input.txt). To fetch it again, run `python download_tiny_shakespeare.py` from this directory.
