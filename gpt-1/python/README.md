# GPT tutorial 1 in Python

This folder contains the guided notebooks. Start with [Lesson 1: read and inspect the training text](lesson_01_dataset.ipynb), then continue to [Lesson 2: character-level tokenization](lesson_02_character_tokenization.ipynb), [Lesson 3: next-token examples](lesson_03_training_examples.ipynb), [Lesson 4: a bigram model](lesson_04_bigram_model.ipynb), [Lesson 5: train the bigram model](lesson_05_train_bigram.ipynb), [Lesson 6: self-attention math](lesson_06_self_attention_math.ipynb), [Lesson 7: attention scaling](lesson_07_attention_scaling.ipynb), [Lesson 8: LayerNorm](lesson_08_layer_norm.ipynb), [Lesson 9: a causal attention head](lesson_09_causal_attention_head.ipynb), [Lesson 10: multi-head attention](lesson_10_multi_head_attention.ipynb), [Lesson 11: a pre-LayerNorm Transformer block](lesson_11_transformer_block.ipynb), [Lesson 12: token and position embeddings](lesson_12_token_position_embeddings.ipynb), [Lesson 13: a tiny decoder language model](lesson_13_decoder_language_model.ipynb), and [Lesson 14: train the decoder language model](lesson_14_train_decoder_language_model.ipynb). The original tutorial notebook remains at [gpt_dev.ipynb](../gpt_dev.ipynb) for reference.

## Set up the Python environment

Install Microsoft's **Python** and **Jupyter** extensions in VS Code. From this folder, create the project environment and install the notebook kernel:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name gpt1-python --display-name "GPT tutorial 1 (.venv, Python 3.13)"
```

Open the repository root or `gpt-1/` in VS Code. In each notebook, select the project `.venv` as its kernel. The notebooks locate `data/input.txt` when started from the repository root, `gpt-1/`, or this Python folder. The requirements include `ipykernel` for VS Code notebooks, NumPy for PyTorch interoperability, Matplotlib for Lesson 14's loss plot, and the CPU build of PyTorch used by Lessons 3–14. Lessons 1 and 2 do not need PyTorch; Lesson 3 introduces tensors and mini-batches, Lessons 4 and 5 use a bigram model, Lessons 6–13 cover architecture, and Lesson 14 trains a small full decoder. These lessons run locally on a CPU. The PyTorch CPU wheel is pinned in `requirements.txt`; see the [official PyTorch installation](https://pytorch.org/get-started/locally/) and [Matplotlib installation](https://matplotlib.org/stable/install/index.html) guides.

If VS Code does not find the kernel in an existing profile, use an **Empty Profile** and install Microsoft's Python and Jupyter extensions there.

## How the lessons are divided

Lesson 1 has one code cell for loading and inspecting the corpus. Lesson 2 repeats setup, then builds the vocabulary, encodes a toy phrase, and encodes the corpus. Lesson 3 splits the corpus, inspects context/target alignment, and samples a batch. Lessons 4 and 5 implement and train a bigram model. Lesson 6 progresses from loop-based causal averages to query-key attention; Lesson 7 explains score scaling; Lesson 8 makes LayerNorm's axis visible. Lesson 9 assembles one causal attention head. Lesson 10 runs two independent heads, concatenates their channels, projects back to model width, and experiments with dropout in training and evaluation modes. Lesson 11 joins pre-LayerNorm, attention and feed-forward residuals, and a position-wise MLP into one Transformer block; the C and Java versions use a recorded Lesson 10 attention output to isolate this composition. Lesson 12 looks up token and position vectors and adds them before the blocks. Lesson 13 connects those embeddings to two blocks, produces vocabulary logits, measures next-token loss, and generates a continuation. Lesson 14 trains a compact decoder on Tiny Shakespeare, evaluates held-out loss, plots both curves, and samples generated text. The splits follow concepts rather than the source notebook's exact cell boundaries.

C and Java use source files and classes instead of notebook cells. Their numbered steps match the Python lesson concepts and can be selected with **Terminal → Run Task → Run tutorial lesson**. See the [shared lesson map](../README.md#run-lessons-by-step) for the C and Java commands.

Lesson 2 intentionally uses Python lists so the character-to-ID mapping stays visible. Lesson 3 introduces tensors when slicing and stacking batches make the abstraction useful. Lessons 4 and 5 use embeddings, cross-entropy, sampling, autograd, and AdamW. Lessons 6 and 7 use tensors for attention math and scaling. Lesson 8 uses LayerNorm and makes its channel statistics visible. Lesson 9 builds a causal attention head from three `Linear` projections. Lesson 10 uses a `ModuleList` of heads, concatenates their outputs, projects back to model width, and applies dropout during training; the C and Java companions show the deterministic evaluation-mode calculation. Lesson 11 composes two LayerNorm operations, residual additions, and a Linear/ReLU/Linear/dropout feed-forward sequence. Lesson 12 uses `nn.Embedding` for token and position tables; the C and Java examples spell out these lookups. Lesson 13 collects these pieces in a small `TinyGPT` module and produces logits. Lesson 14 runs `loss.backward()` through the full decoder and updates it with AdamW; the C and Java bigram lesson shows the corresponding softmax-cross-entropy gradient and optimizer update using explicit arrays.
